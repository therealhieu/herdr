Herdr Subpanes

Each pane can hold several terminals, shown as tabs inside the pane. Workspaces and tabs work as they do today. A Stack is a new kind of leaf in each tab's split tree. The mockup below is interactive.

Try it

      
    
        
  • Click a subpane tab to switch. Middle-click or × closes it.
    • 
        
  • Click + on a plain pane like nvim to turn it into a stack.
    • 
        
  • Drag a tab onto another pane's center to merge it into that stack, or onto a pane's left or right edge to split it out.
    • 
        
  • Switch to Narrow. Style A falls back to the badge when the tabs don't fit.
    • 
        
  • Open zsh in the api stack, then press Block a background agent. The hidden claude tab turns amber, and so does the api tab.
    • 
        
  • Click the mockup, then use [ ] to cycle, 1–9 to jump, t to add, x to close, ← → to move focus. In herdr these come after the prefix key.
